SOHAM RESUME WEBSITE

This is a simple college project made with:
- HTML
- CSS
- JavaScript

FILES
- index.html: Website structure and content
- style.css: Complete website styling
- script.js: Mobile menu and automatic footer year
- soham-mhatre-resume.txt: Downloadable resume

HOW TO OPEN
Double-click index.html. It will open in your web browser.

HOW TO UPLOAD TO GITHUB
1. Create a new public GitHub repository.
2. Upload all five files from this folder.
3. Open repository Settings.
4. Select Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root) folder.
7. Click Save.
8. Wait a few minutes for the website link.

IMPORTANT
Upload the files themselves to the repository root. Do not upload only the outer
folder or ZIP file.
